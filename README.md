🍫 Chocolate Sales Dashboard

📌 Project Overview

The Chocolate Sales Dashboard is an interactive Excel-based project designed to analyze chocolate sales data and present meaningful business insights through charts, graphs, and visualizations.

🎯 Project Objectives

- Analyze total chocolate sales.
- Identify top-performing chocolate products.
- Understand quantity sold.
- Compare sales performance across products.
- Visualize sales distribution.

🛠️ Tools and Technologies

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Data Analysis
- Data Visualization

📊 Dashboard Features

- Total Sales: 1200
- Total Quantity Sold: 150
- Average Sales: 120
- Chocolate-wise sales performance.
- Quantity sold analysis.
- Sales distribution chart.
- Interactive filters using slicers.

🍫 Products Analyzed

- 5 Star
- Dairy Milk
- KitKat
- Munch
- Perk

📁 Project Files

- "chococo.xlsx" – Excel workbook containing the dataset, analysis, and interactive dashboard.

👨‍💻 Conclusion

This project helps understand chocolate sales performance through Excel data analysis and interactive visualizations. It makes sales information easier to analyze and understand.
